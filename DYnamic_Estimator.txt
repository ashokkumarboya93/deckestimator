1. SECTION-BY-SECTION INPUT INVENTORY (SECTIONS 1 TO 9)
================================================================================

SECTION 1: DECK DIMENSIONS & BLUEPRINT
--------------------------------------------------------------------------------
- Shape Selection (Geometry Options):
  * 'rectangle' (Standard 4-corner deck)
  * 'square' (Equal length and width)
  * 'l_shape' (Two connected rectangular sections)
  * 'multi_level' (Upper and lower terrace platforms)
  * 'custom' (Irregular / polygon custom perimeter)
- Length (ft): Floating point number (e.g., 20.0 ft)
- Width (ft): Floating point number (e.g., 16.0 ft)
- Calculated Usable Floor Area (sqft): Length * Width (or user override for custom)


SECTION 2: DECK COMPONENTS & FEATURES (ADDITIVE SURFACE AREAS)
--------------------------------------------------------------------------------
Users select which architectural features exist and specify square footage or linear dimensions:
1. Railings:
   - Input: Linear feet (LF) OR Square Feet (sqft)
   - Code Conversion Constant: 1 LF of railing = 4.0 sqft billable surface area
2. Stairs & Steps:
   - Input: Total number of stair steps (treads + risers) OR Square Feet (sqft)
   - Code Conversion Constant: 1 Step = 12.0 sqft billable surface area
3. Pergola:
   - Input: Linear feet (LF) OR Square Feet (sqft)
   - Code Conversion Constant: 1 LF = 1.5 sqft billable surface area
4. Privacy Wall:
   - Input: Linear feet (LF) OR Square Feet (sqft)
   - Code Conversion Constant: 1 LF = 2.0 sqft billable surface area (front + back)
5. House Siding Flashing:
   - Input: Square Feet (sqft)
6. Fascia Banding Boards:
   - Input: Linear feet (LF) OR Square Feet (sqft)
   - Code Conversion Constant: 1 LF = 1.5 sqft billable surface area
7. Joists & Framing Substructure:
   - Input: Boolean (includeJoists) OR Joist Sqft
   - Code Conversion Constant: When included without direct sqft, Joist Area = Floor Area * 0.40 (40% of flooring)
8. Support Posts:
   - Input: Count of vertical posts
   - Code Conversion Constant: 1 Post = 6.0 sqft billable surface area


SECTION 3: WOOD SPECIES & MATERIAL SELECTION (8 TYPES)
--------------------------------------------------------------------------------
Affects sanding density, chemical dwell absorption, and labor adjustment:
1. 'pt_pine' (Pressure-Treated Southern Yellow Pine) -> 0% labor adjustment (Baseline)
2. 'cedar' (Western Red Cedar)                      -> +10% labor adjustment
3. 'redwood' (California Redwood)                   -> +15% labor adjustment
4. 'mahogany' (Honduran / Genuine Mahogany)         -> +20% labor adjustment
5. 'meranti' (Philippine Mahogany / Meranti)        -> +20% labor adjustment
6. 'tigerwood' (Exotic Tigerwood / Muiracatiara)    -> +30% labor adjustment
7. 'teak' (Burmese / Plantation Teak)               -> +35% labor adjustment
8. 'ipe' (Brazilian Walnut / Ipe)                   -> +35% labor adjustment
* Special: 'trex' / 'composite'                     -> -55% labor discount (Cleaning/Pressure washing scope ONLY)


SECTION 4: SITE ACCESSIBILITY & ELEVATION
--------------------------------------------------------------------------------
Affects ladder rigging, safety harness setups, staging, and technician mobility:
1. 'ground' / 'ground_level' (0 - 2 ft off grade)   -> +0% labor hours (0 fixed hours)
2. 'low' / 'first_story' (2 - 4 ft or 4 - 8 ft)     -> +15% labor hours (or 4.0 fixed hours)
3. 'second' / 'second_story' (8 - 12 ft)            -> +35% labor hours (or 8.0 fixed hours)
4. 'roof' / 'high_work' (> 12 ft elevation)         -> +60% labor hours (or 16.0 fixed hours)


SECTION 5: EXISTING DECK FINISH & COATING
--------------------------------------------------------------------------------
Used for diagnostic stripping heuristics (no direct standalone price impact):
1. 'bare_weathered' (Uncoated, gray oxidized wood fibers)
2. 'maintained_penetrating' (Light penetrating oil toner in good condition)
3. 'oil_one_coat' (Semi-transparent oil stain, mild fade)
4. 'heavy_oil_buildup' (Multiple previous layers of oil/alkyd stain)
5. 'film_former' (Waterborne synthetic acrylic / urethane hybrid)
6. 'solid_paint' (Heavy solid color stain or latex exterior porch paint)


SECTION 6: RESTORATION SCOPE OF WORK (8 SERVICES + NO COATING)
--------------------------------------------------------------------------------
Determines the chemical prep level, finish column, and production speed:
1. 'cleaning' / 'pressure_washing' (Deep sodium hypochlorite/percarbonate wash)
2. 'wood_brightening' (Oxalic acid pH balancing neutralizer)
3. 'stain_stripping' / 'paint_removal' (Sodium metasilicate / caustic stripper)
4. 'sanding' / 'mechanical_sanding' (Rotary / orbital deck restoration sanding)
5. 'staining' / 'deck_staining' (Oil or waterborne protective deck stain)
6. 'sealing' / 'deck_sealing' (Clear hydrophobic seal coating)
7. 'waterproofing' / 'waterproofing_barrier' (Deep penetrating moisture barrier)
8. 'no_coating' (Customer requests bare clean wood with no chemical sealant)
Stain Finish Column Selection:
- 'sealer' (Clear sealer or transparent natural toner)
- 'semi' (Semi-transparent stain, medium pigment)
- 'semi_solid' (Semi-solid heavy pigment stain)
- 'solid' (Solid color opaque coating)


SECTION 7: DECK PHYSICAL CONDITION (9 DAMAGE CONDITIONS)
--------------------------------------------------------------------------------
Drives the Dedicated Contractor Structural Repair Engine:
1. 'good' (Deck is structurally sound; zero repairs; mutually exclusive option)
2. 'crack' (Surface checks and structural splits requiring epoxy filler)
3. 'rotted' (Dry or wet rot requiring framing assessment and board demolition)
4. 'warped' (Cupped, crowned, or twisted deck planks requiring replacement)
5. 'loose_board' (Popped fasteners and squeaking/bouncing floor planks)
6. 'water_damaged' (Soft/delaminated spongy wood from chronic pooling)
7. 'peeling' (Curling, flaking finish requiring mechanical feather sanding)
8. 'weathered' (Severe gray cellulose breakdown)
9. 'mold' / 'mildew' (Deep black/green organic spores requiring fungicide)


SECTION 8: UPLOAD PHOTOS (OPTIONAL)
--------------------------------------------------------------------------------
- Photo file attachments (JPEG/PNG) for senior estimator verification.


SECTION 9: PROJECT INFORMATION & PROPERTY LOCATION
--------------------------------------------------------------------------------
- Project Name (Required): Name of deck project / property
- Property Address: Street address
- City, State, ZIP: Location for dispatch and travel distance calculation
- Travel Minutes (numeric, default: 30 minutes)

2. FORMULA F1: TOTAL BILLABLE SURFACE AREA CALCULATION (A)
================================================================================

Total Billable Surface Area (A) is the sum of all restored wooden surfaces:

  A = A_floor + A_railings + A_stairs + A_pergola + A_privacyWall
      + A_siding + A_posts + A_joists + A_fascia + A_other

Component Formula Breakdown:
--------------------------------------------------------------------------------
Component         | User Input Units       | Hard-Coded Conversion Formula
--------------------------------------------------------------------------------
Flooring          | Length (ft), Width (ft)| A_floor = Length * Width
Railings          | Linear Feet (LF)       | A_railings = LF * 4.0 sqft
Stairs            | Step Count             | A_stairs = Steps * 12.0 sqft
Pergola           | Linear Feet (LF)       | A_pergola = LF * 1.5 sqft
Privacy Wall      | Linear Feet (LF)       | A_privacyWall = LF * 2.0 sqft
House Siding      | Direct Sqft            | A_siding = Direct Sqft
Posts             | Post Count             | A_posts = Posts * 6.0 sqft
Joists / Framing  | Boolean Checkbox       | A_joists = A_floor * 0.40
Fascia Banding    | Linear Feet (LF)       | A_fascia = LF * 1.5 sqft
Other Features    | Custom Direct Sqft     | A_other = Direct Sqft

* Rounding: All individual component areas and total area A are rounded to 2 decimal places.
* Rule: If A <= 0, the engine throws a ValidationError.

3. FORMULA F2 & F3: JOB PREPARATION CLASSIFICATION & RATE CARD LOOKUP
================================================================================

Step 1: Determine Job Preparation Level ('prep')
--------------------------------------------------------------------------------
- Has Stripping? = Selected services contain 'stain_stripping', 'paint_removal', or 'deck_stripping'
- Has Sanding?   = Selected services contain 'sanding', 'mechanical_sanding', or 'deck_sanding'

Decision Tree:
  IF (Has Stripping AND Has Sanding) -> prep = 'strip_sand'
  ELSE IF (Has Stripping)            -> prep = 'strip'
  ELSE                               -> prep = 'clean'

Step 2: Determine Finish Column ('col')
--------------------------------------------------------------------------------
- If 'no_coating' is selected        -> finish = 'none', col = 'sealer'
- Else if Stain Type is 'semi_solid' -> col = 'semi_solid'
- Else if Stain Type is 'solid'      -> col = 'solid'
- Else if Stain Type is 'sealer'     -> col = 'sealer'
- Default                            -> col = 'semi'

Step 3: Rate Card Base Lookup Table ($/sqft) [HARD-CODED CONSTANTS]
--------------------------------------------------------------------------------
The official Deck Restoration Plus Base Rate Matrix [low, high]:

PREPARATION LEVEL   | Sealer / Clear  | Semi-Transparent | Semi-Solid      | Solid Coating
--------------------+-----------------+------------------+-----------------+-----------------
'clean'             | [$2.50, $3.00]  | [$3.00, $3.50]   | [$3.25, $3.75]  | [$3.50, $4.00]
'strip'             | [$3.00, $3.50]  | [$3.50, $4.00]   | [$4.25, $5.00]  | [$5.00, $6.00]
'strip_sand'        | [$3.50, $4.50]  | [$4.00, $4.50]   | [$4.75, $5.50]  | [$5.50, $6.50]

Special Adjustment Rule (Sanding without Stripping):
  When a customer selects Sanding without Chemical Stripping, the clean rate is
  incremented by the exact delta between 'strip_sand' and 'strip':
    Delta_Low  = rateCard.strip_sand[col][0] - rateCard.strip[col][0]
    Delta_High = rateCard.strip_sand[col][1] - rateCard.strip[col][1]
    lo = lo + Delta_Low
    hi = hi + Delta_High

4. FORMULA F4 & F5: STACKED FINISH SURCHARGES & UNIT RATE INTERPOLATION
================================================================================

Stacked-Finish Add-On Formula (F4):
--------------------------------------------------------------------------------
When multiple finishing coats are requested (e.g. Staining + Sealing + Waterproofing):
  FinishList = ['staining', 'sealing', 'waterproofing'] that are selected
  FinishCount = FinishList.length
  FinishAddonPerSqft = $1.00 per sqft (Hard-coded constant: addonPerSqft = 1.0)

  FinishAddon = MAX(0, FinishCount - 1) * 1.00

Interpolated Base Unit Rate Formula (F5):
--------------------------------------------------------------------------------
The platform uses the exact midpoint (ratePosition = 0.50):

  BaseUnitRate(pos) = (lo + (hi - lo) * pos) + FinishAddon
  sqftPrice         = BaseUnitRate(0.50)

Base Price Calculation:
  BasePrice = A * sqftPrice

9. FORMULA F13: MOBILIZATION, TRAVEL SURCHARGES & MINIMUM JOB FLOOR
================================================================================

Travel Distance Evaluation:
--------------------------------------------------------------------------------
- Free Travel Radius: 45 Minutes (freeMinutes = 45)
- Standard Travel Mobilization Fee: $200.00 (fee = 200)

Decision Logic:
  IF (travelMinutes > 45 minutes) {
      isFarDistance = TRUE
      travelFee = $200.00
      minJobPrice = $3,000.00  (minJob.far = 3000)
  } ELSE {
      isFarDistance = FALSE
      travelFee = $0.00
      minJobPrice = $2,500.00  (minJob.near = 2500)
  }

10. FORMULA F14 & F15: FINAL TOTAL ESTIMATION & RANGE CALCULATION
================================================================================

1. Pure Calculated Estimate (No Floor Enforced):
   CalculatedSubtotal = BasePrice + LaborAdjustment + TravelFee
   CalculatedTotal    = round(CalculatedSubtotal)

2. Standard Dispatched Price (With Minimum Floor Applied):
   FloorTotal = MAX(CalculatedTotal, minJobPrice)
   minJobApplied = CalculatedTotal < minJobPrice

3. Range Estimates (Low / High):
   LowCalculated  = round( (A * BaseUnitRate(0.00)) + LaborAdjustment + TravelFee )
   HighCalculated = round( (A * BaseUnitRate(1.00)) + LaborAdjustment + TravelFee )
   LowPrice       = MAX(LowCalculated, minJobPrice)
   HighPrice      = MAX(HighCalculated, minJobPrice)

4. Client Q12 Policy Compliance:
   Homeowners see ONLY ONE TOTAL NUMBER (FloorTotal) with zero confusing line-item
   breakdown, while Contractors & Administrators see the complete operational ledger.

11. DAMAGE CONDITION & STRUCTURAL REPAIR PRICING ENGINE
================================================================================

Section 8 Damage Repair Unit Costs (Hard-Coded Constants):
--------------------------------------------------------------------------------
Repair Item                             | Material Cost | Labor Cost | Total Cost
----------------------------------------+---------------+------------+------------
Structural Moisture & Frame Inspection  | $0.00         | $150.00    | $150.00 fee
Rotted / Cupped Board Replacement       | $20.00/board  | $25.00/brd | $45.00 / board
Crack & Split Wood Epoxy Filler         | $5.00/board   | $10.00/brd | $15.00 / board
Loose Plank Countersinking / Fastening  | $3.00/board   | $9.00/brd  | $12.00 / board
Peeling Scrape & Feather Sanding        | $0.00         | $100.00    | $100.00 flat

Overlap Prevention Business Rules:
--------------------------------------------------------------------------------
1. Good Condition Exclusion:
   If 'good' is selected, ALL damage line items are suppressed ($0 repair cost).
2. Rotted + Water Damaged Shared Inspection:
   If both 'rotted' and 'water_damaged' are checked, only ONE $150 inspection fee
   is billed, preventing duplicate diagnostic charges.
3. Crack + Loose Fastener Overlap Prevention:
   If a board exhibits both a structural crack and loose fasteners, the board is
   marked for complete replacement ($45.00). The engine does NOT bill $15 for crack
   epoxy plus $12 for refastening, saving the homeowner from double charges.
4. Peeling Coating Overlap with Chemical Stripping:
   If the deck requires chemical stripping, peeling surface prep is $0 because
   the caustic chemical stripper inherently dissolves and removes peeling coatings.
5. Weathered (5%) and Heavy Mold (15%) Admin Switches:
   Weathered labor (+5%) and Mold labor (+15%) are gated behind administrative
   switches and remain OFF by default until verified on site.

12. CONTRACTOR WHOLESALE DISCOUNT FORMULAS
================================================================================

Contractors receive an automated trade tier discount on all estimations:

  Standard Tier 1: 10% Wholesale Discount
  Verified Pro:    15% Wholesale Discount
  DRP Elite Pro:   20% Wholesale Discount

Calculation:
  DiscountPercentage = contractorTierDiscount (default: 10.0%)
  DiscountAmount     = round2( TotalEstimate * (DiscountPercentage / 100.0) )
  ContractorPrice    = MAX(0, TotalEstimate - DiscountAmount)

Display UX:
  The estimated price box renders the original price struck-through ($1,000)
  and renders the discounted price ($900) alongside an interactive 10% discount
  checkbox that recalculates live when toggled.

   - Wood = 9.20 * 0% = 0 hours
   - Access = 9.20 * 0% = 0 hours

7. Pure Calculated Total:
   - CalculatedTotal = $1,495.00 + $0.00 + $0.00 = $1,495.00

   - minJobPrice = $2,500.00
